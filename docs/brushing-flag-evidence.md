# 刷单成本判定的旗帜证据

成本免计仍要求蓝色旗帜与卖家备注中的独立 `by` 标记同时满足。`by6王娜`、`BY 蔡果` 可命中；`bypass` 不命中；“买家秀”的计成本优先级不变。

订单台商品旗帜缺列、为 null 或为空白时，可按同店原始聚水潭表的明确内部订单号补全。显式店铺名称优先于文件店铺提示；没有任何店铺依据的原表不能作为免计成本依据。

已有非空实时旗帜保留。原表同一内部订单有多种旗帜时不补全；实时商品行的明确旗帜与原表冲突时，不将同单的空旗帜行补成蓝旗。合并主订单只有全部成本行一致为蓝旗才继承蓝旗，不能扩大某一行的免计范围。

补全必须发生在缺价/历史成本判断之前，成本覆盖后的补全也使用同一规则。核算明细保留内部订单号、旗帜补全说明及刷单成本计零说明，不删除原始费用行。

回归覆盖：三平台全链路、缺列/null/空白、重复执行、ID规范化后冲突、店铺别名、跨店同号、未知店铺、原表冲突、实时非蓝旗、混合旗帜和非by备注。

发布验收按原始订单及商品编码核对计零行，而非只看店铺成本合计。已结账快照和已核定实发不随新计算覆盖；其更正须另走历史审计流程。
