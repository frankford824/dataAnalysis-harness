# 台账界面与验证

## 组件选择

以现有 Vue 3 / Naive UI 为基础，统一 Select、Tabs、DataTable、Button、Dialog、Drawer 和消息反馈。图标使用 `@lucide/vue`，按需打包。没有同时引入另一套完整组件库。

调研来源：

- [Naive UI](https://github.com/tusen-ai/naive-ui)：Vue 3 组件、主题覆盖、选择器和数据表格。
- [Element Plus Select](https://github.com/element-plus/element-plus/blob/dev/docs/en-US/component/select.md)：折叠标签、已选项提示和自定义标签。
- [PrimeVue DataTable](https://primevue.dev/datatable/) / [Tabs](https://primevue.dev/tabs/)：表格和页签的交互组织。
- [Lucide](https://github.com/lucide-icons/lucide)：导航和操作图标。

本次采用 Naive UI 标准控件补齐现有实现，避免同时维护两套表单、弹层和主题。多选显示一个实际名称，附已选数量和可逐项移除的完整清单；不使用会将全部名称折叠掉的 responsive 标签模式。

## 界面约定

- 主色 `#3468f0`，正文 `#243247`，页面底色 `#f6f8fb`；控件常用高度36px、圆角6px。
- 所有页面统一导航、标题、筛选、按钮和反馈；桌面、窄窗口及手机均检查。
- 店铺和人员多选保留实际名称，可打开已选清单删除单项或清空。筛选名称不会因展开清单而误选其他店。
- 提成设置和汇总采用 DataTable，固定操作列，金额右对齐；窄屏减少次要列，保留名称、金额或比例及操作。
- 页签使用 Tabs 的标准选中样式，支持方向键、Home、End、Enter和空格；长页签栏内部滚动。
- 数据与店铺分为待办事项、收到的表、月份进度；文件未就绪时禁用预览并说明原因。
- 读取请求取消过期请求并忽略迟到结果；切换店铺或月份时不接受前一个范围的返回值。
- 保存、重算等业务动作不重复提交；忙碌时显示状态。页面分片失败显示刷新入口，不自动刷新丢失编辑。
- 费项编辑保留未保存草稿；切换标签和刷新不覆盖草稿。试算绑定当时的规则和店铺，改动后重新试算；离开有未保存修改的页面会提醒。
- 新表设置按用户习惯从第1行显示表头，接口仍使用原来的0基索引。未选择类型或列含义时直接提示；试算绑定当时设置。
- 原文件预览保留源单元格值。姓名、工号、订单号和金额不以缩写代替。

## 已覆盖的检查

| 页面 / 区域 | 验证内容 |
|---|---|
| 提成设置 | 长店名、多选清单、逐项移除、状态切换、键盘切换、选中行、手机列表 |
| 提成批量操作 | 隔离工作区中勾选两件商品、预览修改、确认保存、回读状态及完成提示 |
| 金额汇总 | 页签、人员与店铺筛选、明细返回、分页、导出入口及金额展示 |
| 月度总览 | 真实数据、月份对比、页签键盘操作、店铺行进入损益、空数据及失败提示 |
| 月度损益 | 店铺与月份切换、已结账状态、科目下钻、资料页签、忙碌状态 |
| 数据与店铺 | 店铺资料三个页签、文件清单、原表预览入口、新店弹窗、加载错误 |
| 费项 | 平台标签、规则编辑、未保存草稿跨标签保留、离开提醒、试算失效、手机标签滚动 |
| 新表设置 | 隔离工作区的真实上传文件、表头行号、文件类型、列含义、缺项校验和不可保存状态 |
| 搜索 / 原表 | 真实订单搜索、来源定位、打开原表、分页、抽屉宽度、关闭和请求取消 |
| 通用反馈 | 焦点、悬停、按下、禁用、重复点击、请求错误、页面分片加载失败 |

前端自动回归命令：`cd ledger/web && pnpm test`，覆盖请求先后顺序、取消、编辑保留、试算绑定、重复操作和错误消息。构建命令：`pnpm build`。本轮原有非 slow 测试1072项通过，14项slow测试未运行。

浏览器只读预览使用真实台账接口；写入流程使用仓库外独立工作区。没有为了界面测试修改线上提成规则、费项、结账或原文件。上述清单是本轮覆盖范围，不代表所有设备、数据组合或未来状态均不存在缺陷。

## 前端发布

`tools/deploy/win/deploy-ui.ps1` 仅允许静态资源和 VERSION。发布前校验旧版本和覆盖文件哈希，保存 before.zip；先复制新哈希资源，最后原子替换入口和版本文件。保留旧资源，并保持服务运行。发布后回读首页和版本；失败时恢复入口和版本。

构建产物内的第三方CSS模板可能保留行尾空格，源码执行 diff 检查，构建产物按构建和哈希清单验证，不手工改写带内容哈希的JS文件。
