# 运费复核页面

入口：侧栏“运费复核”，以及账期损益表的“发货运费”。支持月份、店铺、平台范围。

本次只增加已有核算记录的只读对照，不执行逐笔运费审计、重算、补扣、结账更正或提成调整。

## 金额与状态

- 账内已计入：已结账店铺使用结账原记录，人工核定结账优先使用留档金额；未结账店铺使用当前试算。
- 后续试算：使用同一店铺、月份最新保存的试算。来源同步、留档和金额完整后才允许对照。已结账无后续试算、资料不完整或没有完整金额时，金额保持未知，不显示为零。
- 试算差额：完整试算减账内金额。尚未核实，不代表应补扣金额。全范围有一店不可比较时，不展示范围总差额；“试算有变化”组可展示该组净变化，并列出增加、减少的店铺数，避免相互抵消被当成无变化。
- 商品分摊待核对：只读取完整试算中发货运费的分摊待核对项。费用已在店铺或订单层保留，不能重复补扣。
- 试算资料未齐：描述该次试算的来源或留档状态，不承诺后台任务正在运行。更新按钮只读取已有记录。

首页按问题归组到店铺；原账与后续试算在依据抽屉中按准确编号切换，时间、编号和逐行来源按需展开。此处费用转为正数显示，退费冲减允许负数。

## 一致性

页面读取返回范围校验值；CSV 导出固定同一月份、平台、店铺、问题组与校验值。依据变化时拒绝导出旧结果并要求刷新。缺失金额留空，保留状态、分摊说明和记录编号供追溯。

后台检查新记录只提示“有新核算结果”，不静默替换正在核对的数据。切换月份或店铺清除旧数据和抽屉；URL 保存当前范围，刷新后保持一致。

接口仅 GET `/api/freight-review` 与 `/api/freight-review/export.csv`，没有财务写入接口。
