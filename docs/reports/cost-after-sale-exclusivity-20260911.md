# 售后、补发、代发成本核查

核查日期：2026-09-11。依据本次八张截图、原始表格、聚水潭订单接口、订单台数据库和台账明细逐项核对。截图里的聊天内容作为核查材料；实际规则采用用户在本任务中的明确确认。

## 已确认的规则

- 退款成功，且货物状态为买家未收到货、买家已退货或卖家已收到退货：对应商品成本从原下单月份扣除。
- 退款关闭，或买家已收到货：继续计算成本。仅有“售后已确认”不等于应当清零。
- 补发订单仅计补发成本，不同时计商品成本。只依据补发自身的售后判断是否归零，不用原商品的退款抹去另行补发的支出。
- 商品编码包含 DF，大小写不限：ERP 商品成本和补发成本计 0；供应商实际代发支出由代发表单独核算。
- 未取得可靠价格，不能当作零成本。取消、代发及符合售后规则的已知零成本，保留带原因的 0 元明细，避免又被结账检查误报为缺少成本。
