# 1688 推广费用

订单行推广费 = 本店本月推广表中相同商品ID的消耗量合计 ÷ 本店本月原始订单明细中该商品ID出现的行数。

推广表字段为商品ID、消耗量，订单明细对应 Offer_ID。支持重复商品推广记录求和；分母为行数，不是件数或收入比例，不包括订单台额外补入的记录。报表以负数列示费用。

按用户最新确认：商品匹配部分仍按上述公式计算；店铺和发生月份明确、但商品ID未匹配当月订单的推广消耗，按本店当月有商品ID的有效原始订单明细行数进行全店分摊。订单最终推广费是商品匹配分摊与全店分摊之和，不重复计入。此口径替代此前“1688未匹配消耗保留未分摊”的约定。

原始商品ID、文件、行号和金额保留，标记“全店分摊入账”。没有本店当月有效原始订单明细，或月份/店铺不明时仍待核对，不以订单台补入记录代替原始明细，不跨月猜分。

有日期列则按实际日期归月；无日期列需要明确单月文件范围。跨月但没有逐月金额时保留待核对。合计行仅校验，不生成全店托管控制额，也不重复入账。

推广仍为可选资料；已有文件解析失败时不能作为完整金额放行。已结账历史与核定实发不随新增计算口径覆盖。

当前源表声明范围为A1，但实际含多行多列。主要读取器及openpyxl备用路径均须读取真实单元格范围，不能仅凭声明维度判断缺列。
