# 待处理事项中的订单明细

“结账检查”中的“代发商品待确认”和“代发支出待核对”提供“查看订单明细”。清单按本次核算版本读取，不使用后来修改的订单备注替换历史依据。

清单显示平台订单号、聚水潭订单号、商品编码、原记录数量、核算时订单备注、待核对原因及来源文件/工作表/行号。同一订单的不同商品分别列出，顶部同时显示订单笔数和商品明细条数。

“复制全部订单号”复制全部筛选结果中的去重订单号，不限于当前页。“导出全部商品明细 CSV”导出相同筛选条件下的完整清单；长订单号保留 Excel 文本精度。聚水潭合并原始单号中的明确数字店铺前缀拆出为可查询的单号，完整原记录仍显示并随导出保留。

新核算保存完整待处理明细并做文件校验。旧核算的商品范围清单从当次事实留档恢复；支出缺口使用当次提成留档中的主子订单关联和历史模型，并与原检查笔数核对。依据缺失、校验失败或数量不符时返回具体错误，不显示零笔，也不使用当前订单重建历史。

旧留档未保存的备注或数量显示“未留档”。这些展示入口不确认成本、不解除结账检查，也不变更已结账金额或实发提成。
