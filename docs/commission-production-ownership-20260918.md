# 做货产出与抽点分离

产出归属按订单商品明细计算。一位做货人员归属全额；多位做货人员只在做货人员之间按点数比例分摊；抽点人员不占销售额、毛利或经营利润。没有做货人员时不擅自把产出归给抽点人员。历史证据缺少身份或订单行标识时保留原分摊口径。

提成核算基数、应发金额、人工核定、冻结账期及逐单原始证据不改写。汇总中的产出和提成计算采用分离的路径，避免把已纠正的完整产出再次乘链接总点数而抬高提成。

利润构成先在全部分配人明细上计算归属权重，再筛选人员，防止只剩当前人员后错误地拿到全额。商品身份优先于整店身份，因此同一人在不同商品上的做货和抽点可以同时存在。抽点商品保留提成明细，但其产出为零。

历史商品剔除清单沿用，当前计入阶梯利润按新口径计算；原保存记录保留。保存校验摘要加入产出口径版本，部署前打开的旧表单不能静默保存新口径下的结果。

生产只读快照对比六月全部 99 条人员金额：应发、参考提成及核定金额逐行一致，总额均为 103120.84。此数为验证时点，不是固定业务常量。
